# Pokemon-Game-2D

Videojuego de estilo RPG desarrollado en Unity basado en las mecánicas clásicas de la franquicia Pokémon.

Características del Proyecto:
    1. Sistema de Mapa e Interacción
    2. Combates por Turnos
    3. Gestión de Equipos y Captura
    4. Progresión (Experiencia y Estados)
    5. Inteligencia Artificial (NPCs y Entrenadores)
    6. Apartado Visual y Sonoro
